# Wallpapers

Pictures in this folder show up in the app under **Background → Wallpapers** for everyone.

**To add one:** in this folder on GitHub, click **Add file → Upload files**, drop in the pictures, then click **Commit changes**. About a minute later they're in the app (close and reopen it).

**To remove one:** click the picture's file here, then the **⋯** menu → **Delete file** → **Commit changes**.

**Names:** the file name becomes the label.

| File name | Shows as |
|---|---|
| `Sunny at sea.jpg` | "Sunny at sea" |
| `2 Sunny at sea.jpg` | "Sunny at sea", 2nd in the list |
| `Sunny at sea by @kaito.jpg` | "Sunny at sea", with "Art by @kaito" |

Any size or shape works (JPG, PNG, WebP or iPhone HEIC). Tall pictures look best on phones. The app makes its own smaller copies in the `wp/` folder, so don't edit that one.

Only add art you made or have the artist's OK to use, and credit them in the name.
